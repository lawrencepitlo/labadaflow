# LabadaFlow — Finite Implementation Roadmap

## Phase 0 — Foundation
Next.js, Clerk, Supabase, shadcn, schema/migrations, route groups, DAL pattern, Server Action pattern, middleware, money/time/state-machine utilities, seed skeleton.

## Phase 1 — Core Backoffice
Authentication, team onboarding, services, customers, orders, workflow transitions, cancellation, completion, printable slip, dashboard.

## Phase 2 — Customer Portal + Tracking
Portal auth/guards, own orders, order detail/history, profile, customer linking, public tracking.

## Phase 3 — Reports + Settings
Daily/weekly summaries, revenue summary, orders by service, basic settings.

## Phase 4 — Polish + Defense
Marketing site, loading/empty/error states, responsive review, accessibility review, seed data, full defense walkthrough, bug fixing.

## Feature freeze
After all Definition-of-Done and feature-freeze criteria in the Master Plan pass, do not add new product features. Focus on bugs, security, performance, accessibility, polish, deployment, and defense readiness.
